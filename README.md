# webgl-life-game

WebGL2 で GPU シミュレーションを行う Conway's Game of Life です。大きな盤面をテクスチャとして保持し、フラグメントシェーダーで次世代計算を行いながら、ズーム / パン付きでブラウザ描画します。

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開くと起動します。

本番ビルド:

```bash
npm run build
```

## 使い方

- `Start / Pause`: シミュレーションの再生と停止
- `Step`: 1 世代だけ進める
- `Reset`: ランダム初期状態で再生成
- `Clear`: 全セルを死セルにする
- `+ / -` またはマウスホイール: ズーム
- `Mode: Draw / Pan`: 左ドラッグの動作を切り替え
- `Shift + ドラッグ` または右ドラッグ: 一時的にパン
- Draw モードでクリック / ドラッグ: セルの生死を編集

## 実装概要

- 盤面状態は 2 枚の `R8` テクスチャで保持
- 次世代計算は WebGL2 フラグメントシェーダーで実行
- 毎ステップごとに ping-pong で読み取り元 / 書き込み先テクスチャを切り替え
- 描画は別シェーダーで行い、カメラ中心座標とズーム倍率だけを更新して高速にナビゲーション
